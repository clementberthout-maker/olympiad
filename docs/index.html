    Support

    Aide

    Les réponses aux questions les plus fréquentes.

    Faut-il un compte pour suivre un tournoi ?

    Non. Les équipes et les spectateurs rejoignent le tournoi en scannant son QR code ou en saisissant son code d'accès dans l'application. Seul l'organisateur a besoin d'un compte.

    Comment rejoindre un tournoi ?

    Dans l'application, touche « Rejoindre un tournoi », puis scanne le QR code affiché par l'organisateur ou saisis le code d'accès qu'il t'a communiqué.

    Qui peut créer un compte organisateur ?

    Toute personne âgée d'au moins 15 ans. Le compte permet de créer, gérer et partager tes tournois.

    Combien d'équipes puis-je ajouter gratuitement ?

    Jusqu'à 12 équipes (ou joueurs) par tournoi. Au-delà, débloque le tournoi avec un Pass Tournoi ou passe à OLYMPIAD Pro.

    Plusieurs personnes peuvent-elles saisir les scores ?

    Oui, avec un Pass Tournoi ou l'abonnement Pro : invite des co-organisateurs depuis ton tournoi, et choisis pour chacun s'il peut saisir les scores, gérer le tournoi ou le supprimer.

    J'ai changé de téléphone, comment récupérer mes achats ?

    Connecte-toi avec le même compte, puis touche « Restaurer mes achats » dans Mon profil ou sur l'écran des offres. Un Pass Tournoi acheté mais pas encore appliqué peut être utilisé avec « J'ai déjà un Pass Tournoi non utilisé ».

    Comment résilier l'abonnement Pro ?

    L'abonnement se gère dans les réglages de ton compte App Store (iPhone) ou Google Play (Android). La résiliation prend effet à la fin de la période déjà payée.

    Comment supprimer mon compte ?

    Dans l'application : Mon profil, puis « Supprimer mon compte ». Tes données sont supprimées immédiatement. Plus de détails sur la page Supprimer mon compte.

    Le simulateur de ce site enregistre-t-il mes données ?

    Non. Le tournoi que tu crées ici reste dans ton navigateur (stockage local) et n'est envoyé nulle part. Pour un vrai tournoi partagé avec tes équipes, utilise l'application.

    Une question, un problème ?

    Écris-nous par e-mail, avec le nom de ton tournoi si ta question le concerne.
